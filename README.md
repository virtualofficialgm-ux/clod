# Pulse — ИИ-тренер, тренировки и питание

Мобильное веб-приложение (PWA) в стиле iOS «Liquid Glass»: персональные тренировки от ИИ, подсчёт калорий по фото, ИИ-чат с тренером и база знаний о спорте и питании. Ставится на iPhone как обычное приложение: Safari → «Поделиться» → «На экран Домой».

## Что внутри

**Регистрация в стиле Cal AI** — пошаговый опрос с прогресс-баром:
пол → тренировки в неделю → откуда узнали → опыт → пробовали ли другие приложения → график «долгосрочный результат» → рост и вес (колёсики, метрическая/imperial) → дата рождения → цель → желаемый вес (линейка) → «это реалистично» → скорость (черепаха/кролик/молния) → «в 2 раза эффективнее» → где тренируетесь → инвентарь → что мешает → диета → чего хотите добиться → график потенциала → уведомления → «Спасибо, что доверяете нам» → загрузка с процентами → **готовый план** (калории, БЖУ, индекс здоровья, дата достижения цели) → создание аккаунта (Apple / Google / email).

**Вкладки:**
- **Сегодня** — неделя, кольца калорий и БЖУ, вода, тренировка дня, дневник питания, серия дней 🔥
- **Тренировки** — недельная программа от ИИ, разбор техники, режим тренировки с подходами и таймером отдыха, история, пересоздание программы с пожеланиями
- **ИИ-тренер** — чат, который знает ваш профиль и норму
- **Знания** — статьи (питание, тренировки, похудение, набор массы, восстановление, добавки), библиотека упражнений с техникой и ошибками, калькуляторы ИМТ, 1ПМ и пульсовых зон
- **«+»** — скан еды по фото (ИИ считает КБЖУ), описание текстом, вода, вес
- **Профиль** — график веса, цель, тема (авто/светлая/тёмная), выход и удаление аккаунта

## Запуск

```bash
npm install
export ANTHROPIC_API_KEY=sk-ant-...   # ключ из console.anthropic.com
npm run dev                            # http://localhost:5173
```

Продакшен (сервер раздаёт собранное приложение и API на одном порту):

```bash
npm run build
npm start                              # http://localhost:8787
```

Без `ANTHROPIC_API_KEY` приложение тоже работает: программа тренировок, оценка еды по тексту и ответы тренера генерируются офлайн-алгоритмом (с пометкой «офлайн»). Анализ еды по фото требует ИИ.

## Как устроено

| Часть | Где |
|---|---|
| Сервер ИИ (Express + Claude API) | `server/index.ts` — `/api/program`, `/api/meal`, `/api/chat` |
| Расчёт нормы (Миффлин–Сан Жеор, БЖУ, вода) | `shared/nutrition.ts` |
| Схемы данных (zod, структурированный вывод ИИ) | `shared/types.ts` |
| Дизайн-система Liquid Glass | `src/styles.css` |
| Онбординг и аккаунт | `src/onboarding/Onboarding.tsx` |
| Экраны | `src/screens/*` |
| Офлайн-тренер, упражнения, статьи | `src/data/*` |

ИИ — модель `claude-opus-5-5` (меняется переменной `CLAUDE_MODEL`). Программа и анализ еды приходят строго по JSON-схеме, чат стримится.

## Ограничения

- Аккаунты и данные хранятся локально в браузере (localStorage). Для синхронизации между устройствами нужен бэкенд с базой данных.
- Кнопки «Apple» и «Google» создают локальный аккаунт. Для настоящего входа нужно подключить Sign in with Apple / Google Identity с ключами разработчика (место отмечено в `AuthForm`).
- Это не медицинское приложение и не заменяет врача.
