# Parri — Fit и Food

Одно приложение, два раздела с общим планом:

- **Parri Fit** превращает цель в реалистичный план тренировок. Пользователь указывает опыт, оборудование, расписание, предпочтения и ограничения. ИИ предлагает программу, объясняет упражнения и корректирует нагрузку по фактическому выполнению и обратной связи.
- **Parri Food** составляет меню на неделю с учётом бюджета, вкусов, времени на готовку и продуктов, которые уже есть дома. Даёт рецепты, список покупок и замены ингредиентов, помогает использовать остатки и планировать на семью.

По **отдельному согласию** Fit и Food согласуют расписание и цели: в дни тренировок меню добавляет углеводы до и белок после занятия. Согласие можно отозвать в профиле.

Приложение помогает держать режим и не обещает медицинскую диагностику или гарантированный результат. Калорийность по фото — приблизительная оценка.

Ставится на iPhone как приложение: Safari → «Поделиться» → «На экран Домой».

## Функции

**Регистрация** (пошаговая, в стиле Cal AI): пол, опыт, дни и длительность тренировок, рост/вес, возраст, цель и темп, место и инвентарь, предпочтения, ограничения, диета, аллергии и исключения, вкусы, бюджет, время на готовку, продукты дома, согласие на связь Fit и Food, напоминания → план → аккаунт.

**Сегодня** — тренировка по расписанию (или день отдыха), меню на сегодня, приблизительные калории и БЖУ, вода, дневник питания.

**Fit**
- Программа от ИИ под расписание и ограничения
- Дневник: вес и повторы в каждом подходе, оценка тренировки («легко / нормально / тяжело / был дискомфорт»)
- Адаптивная нагрузка: следующий вес и повторы рассчитываются по факту (`shared/progression.ts`); при дискомфорте вес снижается; кнопка «Скорректировать по факту» отправляет дневник ИИ
- Прогресс: выполнение плана по неделям за 8 недель
- Напоминания в дни тренировок
- Подбор тренера и заявка на занятие (сейчас демо-профили; оплата через Parri Pay — позже)
- Сканер тренажёров: фото → ИИ объясняет настройку, технику и упражнение из вашего плана
- Анализ техники по видео — «скоро», только с отдельным согласием
- Знания: статьи, библиотека упражнений, калькуляторы

**Food**
- Меню на неделю: 3–4 приёма пищи, дни тренировок отмечены
- Рецепты: порции, ингредиенты, шаги, замены, «заменить блюдо», «я это съел(а)»
- Список покупок по категориям с ценами, без продуктов, которые есть дома
- Бюджет: оценка стоимости недели и сравнение с бюджетом
- Проверка аллергенов по составу; продукты с неизвестным составом (соусы, смеси) требуют уточнения
- Дневник питания и оценка еды по фото через «+» (приблизительно)

**ИИ** — помощник, который знает план, дневник тренировок и меню.

## Запуск

```bash
npm install
export ANTHROPIC_API_KEY=sk-ant-...
npm run dev            # http://localhost:5173
```

Продакшен: `npm run build && npm start` (http://localhost:8787).

Без ключа работает офлайн-режим: программа и меню строятся встроенными алгоритмами (`src/data/localCoach.ts`, `src/data/recipes.ts`), распознавание фото недоступно.

## Устройство

| Часть | Где |
|---|---|
| Сервер ИИ (Express + Claude API) | `server/index.ts` — `/api/program`, `/api/menu`, `/api/meal`, `/api/equipment`, `/api/chat` |
| Схемы данных | `shared/types.ts` |
| Норма калорий и БЖУ | `shared/nutrition.ts` |
| Адаптивная нагрузка | `shared/progression.ts` |
| Проверка аллергенов | `shared/allergens.ts` |
| Экраны | `src/screens/*`, регистрация — `src/onboarding/Onboarding.tsx` |
| Дизайн | `src/styles.css` |

## Ограничения текущей версии

- Данные и аккаунты хранятся локально в браузере; для синхронизации нужен бэкенд.
- Вход через Apple/Google создаёт локальный аккаунт; настоящий OAuth требует ключей.
- Напоминания работают, когда приложение открыто или установлено на экран «Домой»; push в фоне требует сервера.
- Тренеры — демо-профили; Parri Pay, Parri Tasks и магазины-партнёры — заглушки «скоро».
