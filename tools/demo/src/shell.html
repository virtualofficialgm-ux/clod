Что попробовать

  1. Анна: «Задачи» → «Мои задачи» → «Собрать таблицу цен конкурентов» на проверке → чек-лист → «Принять и оплатить».
  2. Мария: откликнуться на «Логотип для студенческого клуба» со своей ценой; затем Анна выбирает её в «Откликах» — разница уходит в Сейф.
  3. Новый аккаунт: «Начать бесплатно». Код подтверждения появится вверху экрана вместо письма.
  4. «+»: создать задачу, нажать «Оформить с ИИ» и посмотреть итог с комиссией (5% → 2,5% по шкале).
  5. Баланс → «Пополнить»: тестовая оплата картой, деньги приходят на счёт. В «Профиль → Подписка» — Pro.
  6. Профиль: «Рядом», «Аналитика», «Найти людей», поддержка, споры, верификация, бот PARRI (на Pro, например у Ивана).
  7. Иван: взять задачу «Рядом», открыть рабочую комнату и «Отметиться на месте».

Что в демо иначе

  • Писем нет — код показывается на экране.
  • «Оформить с ИИ», перевод и бот работают без ключа Claude: черновик по шаблону, бот отвечает по базе знаний, перевод недоступен.
  • Оплата — тестовая страница Stripe поверх приложения, деньги не списываются. USDT в демо выключен.
  • Админ-панель есть только на сайте, в демо — мобильное приложение.
  • Геолокацию просмотрщик не выдаёт, поэтому «Рядом» честно просит доступ.
  • Чат обновляется раз в несколько секунд, без Realtime.
